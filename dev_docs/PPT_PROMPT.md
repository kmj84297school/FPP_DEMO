## 프롬프트 (여기서부터 복사)

너는 고등학생의 진로활동 탐구 발표자료를 만드는 것을 돕고 있다.
아래 프로젝트 내용으로 **15장짜리 발표 슬라이드**를 만들어줘 (10-A, 10-B는 각각 한 장).

### 절대 지켜야 할 원칙
이 프로젝트의 정체성은 **"정직한 측정"** 이다. 다음을 반드시 지켜라:
- 아래 제공된 수치를 **그대로** 사용하고, 없는 수치를 지어내지 마라.
- 성능 수치에는 **반드시 검증 방법**(GroupKFold 5겹 등)을 병기하라.
- **"완성한 것"과 "계획/한계"를 명확히 분리**해서 서술하라.
- "세계 최초", "혁신적" 같은 과장 표현 금지. 올바른 프레임은
  *"산업에서 검증된 방법론(SciSports, 야구 PECOTA 계보)을 학생 수준에서
  전 과정 재구현하고, 그 한계까지 정량적으로 측정했다"* 이다.
- 실패한 시도도 숨기지 말고 오히려 **배움의 근거로** 제시하라
  (예: 신뢰구간 1차 시도 실패 → 원인 규명 → 해결).

### 디자인

## 슬라이드 구성

**1. 표지**
- 제목: FPP — Football Player Potential AI
- 부제: 공개 데이터로 축구 선수의 미래 능력을 예측하고, 그 불확실성까지 측정하다
- 하단: 2학년 진로활동 탐구 / 데이터·머신러닝 프로젝트

**2. 문제 정의**
- 축구 유망주 평가는 여전히 스카우트의 주관과 경험에 크게 의존한다.
- "지금 잘하는 선수"와 "앞으로 잘할 선수"는 다르다. 후자를 데이터로 말할 수 있을까?
- 핵심 질문: 현재 스탯만으로 2~3년 후를 예측할 수 있는가, 그리고 **그 예측을 얼마나 믿을 수 있는가?**

**3. 1학년 프로토타입과 그 한계** (실패에서 출발했음을 정직하게)
- 1학년: 요청 시 FBref 실시간 크롤링(Selenium) → 규칙 기반 점수 → 리포트
- 부딪힌 벽 4가지: Cloudflare 차단 / 응답 지연 / 서버 배포 불가 / **머신러닝 학습 자체가 불가능**
- 규칙 기반의 근본 문제: 가중치를 내가 정했으므로 "맞다"는 근거가 없음
- → 구조를 갈아엎기로 결정

**4. 2학년 아키텍처 대전환** (Before/After 비교 도식으로)
- Before: `요청 → 실시간 크롤링 → 규칙 점수 → 리포트`
- After: `사전 구축 데이터셋 → 사전 학습 모델 → 서빙은 로드만`
- 결과: 크롤링 제로 / 즉시 응답 / 정적 배포 가능 / **실제 ML 학습 가능**

**5. 데이터**
- 출처: worldfootballR 공개 아카이브 (원출처 FBref) + 2023-24 / 2024-25 시즌 추가 반입
- 규모: **2018~2025 시즌, 19,783행 × 169열** (빅5 리그 필드플레이어)
- 전처리: 8개 카테고리 병합, 다중 소속팀 시즌 합산, 무결성 감사 완료
- 정직성 포인트: **동명이인 33명 확인** → 이름 조인 전면 금지, fbref_id로만 결합
- 서로 다른 형태의 3개 소스(RDS 아카이브 / 단일 통합 CSV / 팀별 카테고리 CSV 묶음)를
  하나의 스키마로 통합. 생년을 못 구한 선수는 추정하지 않고 **연결을 포기**(오결합 방지)

**6. 능력 점수 — 이중 렌즈 설계** (핵심 아이디어, 도식 권장)
- 문제: "포지션" 라벨은 너무 거칠다. 공격형 풀백을 일반 수비수 기준으로 재면 저평가된다.
- 해결: **포지션 렌즈 + 스타일 렌즈의 평균**
  - 포지션 렌즈: FW/MF/DF별 가중치
  - 스타일 렌즈: 11개 플레이스타일 자동 분류 후 스타일별 가중치
- 실제 사례: TAA(공격형 풀백) 포지션 렌즈 49.5 → 스타일 렌즈 69.1로 구제
- 순환성 차단 설계: 스타일 **판별**은 '구성비(shape)' 지표로, 점수 **가중**과 분리

**7. 라벨 설계 — 무엇을 "정답"으로 볼 것인가**
- 라벨 = t+2 ~ t+3 시즌(900분 이상 출전)의 능력 점수 평균 (단일 시즌 노이즈 제거)
- 빅5 리그에서 사라진 선수는 **별도 분류 모델**로 분리 (생존 편향 명시 처리)
- 교차검증은 **GroupKFold(선수 단위)** — 같은 선수가 학습/검증에 동시에 들어가면 누수

**8. 모델 성능 — 두 개의 모델** (표로, 검증 방법 반드시 병기)

| | 성장기 모델(U23) | 성숙기 모델(24~38세) |
|---|---|---|
| 잔존 분류 AUC | 0.693 ± 0.032 | **0.732 ± 0.013** |
| 미래 능력 MAE | 6.00 | **5.31** |
| R² | 0.306 | **0.500** |
| 코호트 행 수(라벨) | 2,268 (1,638) | 5,214 (2,799) |
| 80%/50% 구간 실측 커버리지 | 82.6% / 52.2% | 83.2% / 53.2% |
| 검증 | GroupKFold 5겹 | GroupKFold 5겹 |

- 흥미로운 발견: **베테랑 예측이 유망주 예측보다 정확하다.**
  → 이미 자리 잡은 선수의 커리어 궤적이, 아직 증명되지 않은 유망주의 "터질지 말지"보다 예측하기 쉽다.
- 코호트를 2018~2022로 넓히고 회귀 타깃을 Δ로 바꾼 뒤의 수치 (10번 슬라이드 참조)

**9. 자체 발견: "수준보다 기울기"**
- Δ(성장 궤적) 피처가 전체 중요도의 **25%** 차지
- 그 중 1위는 `d_grp_progress` = **전진 능력의 성장분**
- 이 피처를 쓰려면 직전 시즌 기록이 필요한데, 2023-24 시즌을 추가로 확보해
  현재 예측 대상의 **56%(475명 중 264명)** 가 실제로 이 신호를 갖게 됐다 (확보 전 0명)
- 해석: 지금 얼마나 잘하느냐(수준)보다, **얼마나 빠르게 늘고 있느냐(기울기)** 가 미래 신호다.

**10-A. 두 번째 실패와 해결 — "왜 최고 선수가 하락 예측인가"** (하이라이트)
- 발견: 하피냐(현재 88.7)의 2~3년 후 예측이 72.8. 직관에 어긋나 원인을 조사.
- 배제한 가설 ①: 스케일 불일치? → 아님. 라벨과 현재 점수는 동일 산식이고,
  U23 코호트는 실제로 53.3 → 53.8로 **올랐다**.
- 배제한 가설 ②: 모델이 과도하게 축소? → 아님. OOF 보정 기울기 0.870/0.926으로
  **1보다 작고**, 선형 보정을 적용해도 MAE가 그대로(5.98→5.98).
- 진짜 원인: **학습 라벨에 85점 이상이 0명**(99%tile 73.7/76.4). 트리 모델은
  학습 라벨 밖으로 외삽할 수 없어 예측 천장이 74로 고정 → 그 위 선수는 무조건 하락.
  실증적으로 80~85점 선수의 실제 하락폭은 **-6.8**인데 모델은 **-16**을 예측.
- 해결: 예측 대상을 **레벨 → Δ(변화량)** 으로 전환. "몇 점이 될까" 대신
  "이런 선수는 보통 몇 점 오르내릴까"를 학습하고 실제 현재 점수에 더한다.
- 결과: 하피냐 72.8 → **82.1** (실증 하락폭 -6.8과 거의 일치), MAE·R²도 동시 개선.
- 남은 한계도 명시: Δ 방식은 학습 범위 밖에서 낙관 편향이 있어, 상위 1.3%(19명)에게는
  "모델 검증 범위 밖" 경고를 그대로 노출한다.

**10-B. 첫 번째 실패와 해결 — 신뢰구간**
- 목표: 점 추정("75점") 말고 구간("64~86점")을 제시하고 싶었다.
- 1차 시도: 부트스트랩 신뢰구간 → **실측 커버리지 29.3%** (명목 80%인데 실제로는 29%만 포함 → **완전 실패**)
- 원인 규명: 모델 자체의 불확실성만 셌고, **데이터에 내재된 잔차 불확실성을 빠뜨렸다.**
- 해결: `구간 = mu ± z × sqrt(σ_모델² + σ_잔차²)`
- 보정 후 실측 커버리지 **82.0% / 52.1%** (명목 80% / 50%와 거의 일치) → 성공
- 이 실패가 프로젝트에서 가장 많이 배운 지점

**11. 결과물 — 웹 서비스** (이미지: 01_landing.png, 02_ceiling_rank.png)
- GitHub Pages 정적 배포 (서버 없음, 요청 시 연산 없음)
- 2024-25 시즌 기준 **검색 1,692명 / 예측 제공 1,455명**
- 3가지 정렬: 현재능력순 / 2~3년 후 상한순 / **상승 여력순**(숨은 유망주 발굴)

**12. 선수 리포트** (이미지: 05_yamal_top.png 또는 04_yamal_full.png)
- 예시: 라민 야말 (17세, 바르셀로나) — 현재능력 84.0 / 2~3년 후 예측 80.3 / 80% 구간 상단 91.7
- 제공 정보: 이중 렌즈 분해, 능력 그룹 레이더, 강점/약점, 플레이스타일 판별 근거,
  잔존 확률, 예측 구간, **실제 결과가 있는 과거 유사 선수 10명**, 정성 시그널
- 설계 판단 ①: 헤드라인 숫자로 점 추정(mu) 대신 **80% 구간 상단**을 사용
  → 지어낸 숫자가 아니라 이미 계산된 구간을 다르게 강조한 것
- 설계 판단 ②: 처음엔 이 숫자를 "잠재력 상한"이라 불렀는데, 모델이 예측하는 건
  커리어 전성기가 아니라 **정확히 2~3년 후**라서 문구를 전부 기간 명시로 고쳤다.
  측정한 것보다 큰 주장을 하는 이름은 그 자체로 결함이라고 판단

**13. 한계 — 숨기지 않고 기록한 것들**
- 데이터: 2025-26 시즌은 공개본에 고급지표 블록이 없어 미반입 (반쪽 점수를 내느니 제외)
- 2024 시즌 반입 시 생년 미확보 314명은 추정 대신 별도 ID 부여 → 시즌 간 이력 미연결
- 라벨 순환성: 능력 점수로 능력 점수를 예측 → 외부 지표(시장가치 등) 교차검증 필요
- 능력 점수 v2 과제: 박스 포처 저평가, 수비수 팀 강도 편향, 포지션 간 분산 불일치(FW 13.8 vs DF 7.5)
- 미착수: GK 전용 모델, SHAP 해석 레이어
- **라이선스**: 교육·연구 목적은 문제없으나 **상업적 사용 불가** (상업화는 BYOD 또는 정식 라이선스 전제)

**14. 배운 것 / 다음 단계**
- 배운 것 3가지:
  1. 모델을 만드는 것보다 **"얼마나 믿을 수 있는지 측정하는 것"** 이 어렵고 중요하다
  2. 데이터 누수(선수 단위 분할), 생존 편향, 평균회귀 — 교과서 개념을 실제로 밟아봤다
  3. 예쁜 결과보다 **정직한 결과**가 설득력이 있다
- 다음 단계: 2025-26 고급지표 확보, 외부 라벨(시장가치) 교차검증, GK 전용 모델, SHAP 해석
