## 프롬프트 (여기서부터 복사)

너는 고등학생의 진로활동 탐구 발표자료를 만드는 것을 돕고 있다.
아래 프로젝트 내용으로 **16장짜리 발표 슬라이드**를 만들어줘.

### 절대 지켜야 할 원칙
이 프로젝트의 정체성은 **"정직한 측정"** 이다. 다음을 반드시 지켜라.
- 아래 제공된 수치를 **그대로** 사용하고, 없는 수치를 지어내지 마라.
- 성능 수치에는 **반드시 검증 방법**(GroupKFold 5겹 등)을 병기하라.
- **"완성한 것"과 "한계/계획"을 명확히 분리**해서 서술하라.
- "세계 최초", "혁신적" 같은 과장 표현 금지. 올바른 프레임은
  *"산업에서 검증된 방법론을 학생 수준에서 전 과정 재구현하고, 그 한계까지 정량적으로 측정했다"* 이다.
- **실패한 시도와 기각한 실험을 성과와 같은 비중으로** 제시하라. 이 프로젝트에서 가장 배운 지점이다.
- 예측값을 "잠재력"이나 "포텐셜 최대치"로 부르지 마라. 정확한 이름은 **"2~3년 후 능력"** 이고,
  헤드라인 숫자는 **"2~3년 후 상한(80% 신뢰구간 상단)"** 이다.

## 슬라이드 구성

**1. 표지** (이미지: `00_logo_intro.png`)
- 제목: FPP — Football Player Potential
- 부제: 공개 데이터로 축구 선수의 2~3년 후를 예측하고, **그 불확실성까지 측정하다**
- 하단: 2학년 진로활동 탐구 / 데이터·머신러닝 프로젝트

**2. 문제 정의**
- 유망주 평가는 여전히 스카우트의 주관과 경험에 크게 의존한다.
- "지금 잘하는 선수"와 "앞으로 잘할 선수"는 다르다.
- 핵심 질문: 현재 스탯만으로 2~3년 후를 예측할 수 있는가, **그리고 그 예측을 얼마나 믿을 수 있는가?**

**3. 1학년 프로토타입과 그 한계**
- 1학년: 조회할 때마다 실시간 크롤링 → 내가 정한 규칙으로 점수 → 리포트
- 벽 4가지: 사이트 차단 / 응답 지연 / 서버 배포 불가 / **데이터가 안 쌓여 머신러닝 자체가 불가능**
- 규칙 기반의 근본 문제: 가중치를 내가 정했으니 "맞다"는 근거가 없다 → 구조를 갈아엎기로 결정

**4. 2학년 아키텍처 대전환** (Before/After 도식)
- Before: `요청 → 실시간 크롤링 → 규칙 점수 → 리포트`
- After: `데이터를 미리 구축 → 실제 결과로 학습한 모델 → 웹은 결과만 읽음`
- 결과: 크롤링 0회 / 즉시 응답 / 정적 배포 가능 / **실제 ML 학습 가능**

**5. 데이터**
- 출처: worldfootballR 공개 아카이브(원출처 FBref) + 2023-24, 2024-25 시즌 별도 반입
- 규모: **2018~2025 시즌, 19,789행 × 169열** (빅5 리그 필드플레이어)
- 서로 다른 형태의 3개 소스(RDS 아카이브 / 단일 CSV / 팀별 카테고리 CSV 묶음)를 하나의 스키마로 통합
- 정직성 포인트: **동명이인 33명 확인** → 이름만으로 선수를 합치는 것 전면 금지, (이름+생년) 이상으로만 결합.
  생년을 못 구한 선수는 추정하지 않고 **연결을 포기**했다(오결합 방지).

**6. 능력 점수 — 이중 렌즈 설계** (도식 권장)
- 문제: "포지션" 라벨은 너무 거칠다. 공격형 풀백을 일반 수비수 기준으로 재면 저평가된다.
- 해결: **포지션 렌즈 + 플레이스타일 렌즈의 평균**. 스타일은 11종을 자동 분류.
- 실제 사례: 트렌트 알렉산더-아널드 — 포지션 렌즈 49.5 → 스타일 렌즈 69.1로 구제
- 순환성 차단: 스타일 **판별**은 '구성비' 지표로, 점수 **가중**과 분리

**7. 라벨(정답) 설계**
- 정답 = t+2 ~ t+3 시즌(900분 이상)의 능력 점수 평균 — 단일 시즌 운을 줄이기 위해
- 빅5에서 사라진 선수는 **별도의 "잔존 확률" 분류 모델**로 분리 (생존 편향 명시 처리)
- 검증은 **GroupKFold(선수 단위)** — 같은 선수가 학습·검증에 동시에 들어가면 성적이 부풀려진다

**8. 모델 성능** (표. 검증 방법 반드시 병기)

| | 성장기 모델(23세 이하) | 성숙기 모델(24~38세) |
|---|---|---|
| 빅5 잔존 분류 AUC | 0.745 ± 0.020 | **0.759 ± 0.015** |
| 미래 능력 오차 MAE | 5.79 | **5.18** |
| 설명력 R² | 0.346 | **0.521** |
| 80% / 50% 구간 실측 커버리지 | 81.1% / 51.7% | 82.9% / 53.3% |
| 학습 선수-시즌 수(정답 보유) | 2,268 (1,637) | 5,214 (2,800) |
| 검증 | GroupKFold 5겹 | GroupKFold 5겹 |

- 읽는 법: MAE 5.79 = 100점 만점에서 평균 5.79점 틀린다. 80% 구간 81.1% = 약속(80%)과 실제가 일치.
- 흥미로운 발견: **베테랑 예측이 유망주 예측보다 정확하다.** 이미 자리 잡은 선수의 하락 곡선이,
  아직 증명되지 않은 유망주의 "터질지 말지"보다 예측하기 쉽다.

**9. 실패 1 — 신뢰구간이 완전히 틀렸던 이야기** (하이라이트)
- 목표: 점 추정("75점") 대신 구간("64~86점")을 제시하고 싶었다.
- 1차 결과: 명목 80% 구간의 **실측 커버리지 29.3%** → 완전 실패
- 원인: 모델 자체의 흔들림만 셌고, **데이터에 내재된 잔차 불확실성을 빠뜨렸다**
- 해결: `구간 = 예측값 ± z × √(σ_모델² + σ_잔차²)` → 실측 **81~83%**로 약속과 일치
- 이 실패가 프로젝트에서 가장 많이 배운 지점

**10. 실패 2 — "왜 최고 선수가 하락 예측인가"** (하이라이트)
- 발견: 현재 88점인 선수의 2~3년 후 예측이 73점. 직관에 어긋나 원인을 조사했다.
- 배제한 가설 ①: 점수 체계가 달라서? → 아님(같은 산식, 코호트 평균은 오히려 상승)
- 배제한 가설 ②: 모델이 과하게 보수적? → 아님(보정해도 오차가 그대로)
- **진짜 원인: 학습 정답 중 85점 이상이 0명.** 트리 모델은 학습 범위 밖을 예측할 수 없어 천장이 74로 고정.
  실제 그 구간 선수들의 하락폭은 -6.8인데 모델은 -16을 예측했다.
- 해결: 예측 대상을 **"몇 점이 될까(레벨)" → "몇 점 오르내릴까(변화량)"** 로 전환
- 결과: 같은 선수 73 → **82점**(실증 하락폭과 일치), 오차·설명력도 동시에 개선

**11. 기각한 실험 3건 — 안 된 것도 결과다** (표)
| 시도 | 기대 | 실제 결과 | 결정 |
|---|---|---|---|
| 포지션을 7개 세부 역할로 쪼개 채점 | 더 공정한 점수 | 점수의 시즌 간 재현성 하락, 오차 5.79→7.10 | **기각** (역할은 화면 표시용으로만) |
| 정답을 두 시즌 "평균" 대신 "최댓값"으로 | 잠재력 정의에 더 부합 | 오차 5.84→6.24, 상위권도 개선 없음 | **기각** |
| 구간을 분위수 회귀로 직접 추정 | 비대칭 구간 | 명목 80% 구간이 실제 69%만 포함 | **기각** |
- 채택 규칙을 미리 정해 두었다: **"폴드 밖(검증) 지표가 나빠지는 변경은 채택하지 않는다."**
  이 규칙 덕분에 "그럴듯해 보이는 아이디어"를 감이 아니라 수치로 잘라낼 수 있었다.

**12. 성능을 실제로 올린 것** (앞의 실패와 대비되는 슬라이드)
- **잔존 예측 보강**: 소속팀 강도(같은 팀 동료들의 평균 능력), 리그, 선발 비율, 2년간 출전시간 추세를 피처로 추가
  → AUC 0.691→0.723(성장기), 0.734→0.751(성숙기)
- **하이퍼파라미터 탐색**: 54개 조합을 GroupKFold로 탐색하되, **선택 낙관을 드러내려고 다른 분할에서 재확인**한 뒤 채택
  → 최종 AUC 0.745 / 0.759, MAE 5.79 / 5.18
- 발견: 팀 강도가 잔존 예측에서 3번째로 중요한 피처. "리그1의 젊은 선수는 빅5 밖으로 팔려 나간다"는 상식이 데이터에 있었다.

**13. 예측을 설명하다 — SHAP** (이미지: `07_explain_shap.png`)
- 문제: 점수만 보여주면 "왜?"에 답할 수 없다(블랙박스).
- 해결: 선수마다 **어떤 항목이 예측을 얼마나 올리고 내렸는지**를 계산해 화면에 표시
- 예: "직전 시즌 능력이 +19.5 급등 → 예측을 -2.4 낮춤" = 모델이 **평균회귀**를 학습했다는 증거
- 화면에 함께 명시: 기여도는 **이 선수 한 명에 대한 국소 설명이며 인과관계가 아니다**

**14. 결과물 — 웹 서비스** (이미지: `01_landing.png`, `02_ceiling_rank.png`, `03_growth_rank.png`, `10_mobile.png`)
- GitHub Pages 정적 배포. 서버 없음, 요청 시 연산 없음, 첫 로드 266KB
- 2024-25 시즌 기준 **검색 1,692명 / 예측 제공 1,455명**
- 세 가지 정렬: 현재능력순 / 2~3년 후 상한순 / **상승 여력순**(숨은 유망주 발굴)
- 리그·포지션·세부 역할·나이·스타일 필터, 필터 상태가 URL에 저장돼 그대로 공유 가능
- 휴대폰(375px)에서 표를 카드로 전환, 색만으로 정보를 전달하지 않도록 등급 텍스트 병기

**15. 선수 리포트와 비교** (이미지: `06_player_top.png`, `08_prediction_ci.png`, `09_compare.png`)
- 예시: 라민 야말(17세, 바르셀로나) — 현재 84.0 / 2~3년 후 중심값 81.2 / **80% 구간 상단 91.9** / 잔존 확률 95.0%
- 제공: 이중 렌즈 분해, 능력 그룹 레이더, 강점·약점, 스타일 판별 근거, 예측 구간,
  **실제 결과가 있는 과거 유사 선수 10명**, 경기 기록 기반 정성 시그널, 두 선수 비교
- 설계 판단: 헤드라인에 점 추정 대신 **80% 구간 상단**을 쓰되 "상위 10% 시나리오"임을 툴팁에 명시.
  숫자를 지어낸 게 아니라 **이미 계산된 구간을 다르게 강조**한 것.
- 야말은 현재 능력이 학습 정답의 상위 1%를 넘어 **"모델 검증 범위 밖"** 경고가 함께 뜬다(19명, 1.3%).

**16. 한계와 다음 단계**
- 한계(숨기지 않음):
  - 유망주 모델 설명력 R² 0.35 — 변화의 65%는 아직 설명 못 함
  - 상위 1% 선수는 검증 표본이 19명뿐 → 경고 노출
  - **정답의 순환성**: 능력 점수로 능력 점수를 예측 → 외부 지표 검증 필요
  - 골키퍼 전용 모델 미착수, 신규 선수 일부는 과거 이력 미연결
  - **라이선스: 교육·연구는 가능, 상업적 사용 불가**
- 다음 단계: 시장가치 등 외부 지표로 타당성 검증(스크립트·ID 연결표 준비 완료) → 2025-26 시즌 확보 →
  빅5 밖 리그로 "이탈"과 "이적" 구분 → 부상 기록 → 골키퍼 모델
- 배운 것 3가지:
  1. 모델을 만드는 것보다 **얼마나 믿을 수 있는지 측정하는 것**이 어렵고 중요하다
  2. 데이터 누수·생존 편향·평균회귀 — 교과서 개념을 실제로 밟아봤다
  3. **예쁜 결과보다 정직한 결과가 설득력이 있다**
