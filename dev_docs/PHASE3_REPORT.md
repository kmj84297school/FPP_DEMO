## A1. 포지션 세분화 (역할 7분류) — **점수 개편은 기각, 역할 라벨만 채택**

### 무엇을 했나
- `src/scoring_v2.py`: 구성비(shape) z-축으로 DF→CB/FB, MF→DM/CM/AM, FW→W/ST 역할 추론.
  지표 백분위 풀을 시즌×pos → 시즌×role로, 렌즈 가중치를 POS_W(3종) → ROLE_W(7종)로.
  판별 축은 §4-3 원칙대로 shape 피처만 사용(순환성 방지). 스타일 렌즈는 v1 그대로.
- `build/exp/a1_compare.py`: v1 / v2 / v2+role one-hot을 같은 코호트 규칙·같은

  `a1_role_uses.py`: v1 점수를 유지한 채 역할을 피처·k-NN 후보 풀로만 쓰는 경우.

### 해석
- **역할 풀이 점수를 시끄럽게 만든다.** 기저 MAE(미래=현재)가 6.65→8.03으로 커졌다는 건
  v2 점수의 시즌 간 재현성 자체가 낮아졌다는 뜻이다. 원인은 두 가지: 풀이 작아져(CM은
  시즌당 ~90명) 백분위가 거칠어지고, MF 내부·W↔AM 경계가 해마다 흔들려(CM 유지율 36%)
  같은 선수가 시즌마다 다른 풀·다른 가중치로 채점된다.
- 75+ 밴드 MAE는 v2가 낮아 보이지만(5.31 vs 6.24) v2에서는 75+ 표본 자체가 달라져(19→29명)
  비교 불가. 전체 MAE·R²·재현성이 모두 나쁘면 채택할 근거가 없다.
- 역할 라벨은 정보로서는 건전하므로(13/16), **표시용 참고 라벨**로만 싣는다.

### 채택
- 점수 산식: **v1 유지.** `build/01_score_all_seasons.py`는 `scoring_v2.build_scores(pool_by="pos", lens="pos")`를
  호출 — v1과 점수가 바이트 단위로 동일하며(검증 완료) `role`/`role_axis` 열만 추가.
- 화면: 선수 페이지 헤더에 "MF (수비형 MF)"처럼 세부 역할 표시. |축|<0.3이면 "·경계" 표기.
  `index.json`에 `role` 필드 추가(이후 A8 필터용).
- 모델 피처·k-NN 후보 풀에는 쓰지 않음(중립~악화).
- 분산 불일치는 미해결로 남김. 후보: 시즌×포지션 내 표준화(50+10z) — 라벨 정의가 바뀌므로
  별도 실험 필요. 백로그 §D 유지.

## A2. 상위권 외삽의 나머지 반 — 라벨=최댓값 / 분위수 회귀 — **둘 다 기각, 경고문은 실측대로 수정**

### 무엇을 했나
`build/exp/a2_topend.py`: 같은 코호트·같은 GroupKFold 5겹에서 2×2 비교.
라벨 {t+2·t+3 평균(현행), 최댓값} × 구간 {정규 CI(부트스트랩 σ_model ⊕ 잔차 σ, 현행),
분위수 회귀(`reg:quantileerror`, q=0.1/0.25/0.5/0.75/0.9, 교차 방지 정렬)}. 타깃은 전부 Δ.
코호트 행렬에 `fut_ability_max`, `fut_n` 열을 추가했고(`build/lib/cohorts.py`), 학습·예측
스크립트는 `LABEL_COLS`로 라벨 열을 피처에서 제외한다(누수 방지).

(MAE·R²는 각 변형이 학습한 라벨 기준. 최댓값 라벨은 p99가 75.8→78.0 / 76.2→77.7로 상단이 1.5~2점
올라가지만, 두 시즌 보유 비율이 50%/46%라 나머지 절반은 평균과 동일한 값이다.)

### 해석
- **분위수 회귀**: 구간이 정규 CI보다 22~24% 좁고 그만큼 커버리지가 명목(80%)에 크게 못 미친다
  (69~70%). 75+ 밴드에서는 위쪽으로 비대칭(+2.4)이 나오긴 하지만 커버리지·MAE가 모두 나쁘다.
  표본 1.6~2.8k에서 트리 분위수 회귀는 꼬리를 과소추정한다. **기각.**
- **최댓값 라벨**: 단일 시즌 값이라 라벨 노이즈가 커져 자체 라벨 기준 MAE가 0.3~0.4 나빠지고
  75+ 밴드도 개선되지 않는다(6.04→6.49). "잠재력"의 정의에 가깝다는 장점만으로 채택할 근거가
  없다. **기각.**
- **정직한 부수 발견**: Δ 모델의 75+ 밴드 실측 편향은 **+1.0(약간 낙관)**이고 커버리지는
  84~87%로 정상이다. 즉 레벨 타깃 시절의 "구조적 하향(−16)"은 사라졌고, 남은 문제는 표본이
  19/61명뿐이라 오차 수치의 신뢰도가 낮다는 것이다. 사이트의 검증범위 밖 경고문을
  "과도하게 낮게 나온다"(레벨 모델 시절 문구)에서 이 실측대로 고쳤다.
- **부트스트랩 앙상블 평균이 단일 모델보다 낫다**: 같은 설정에서 단일 모델 OOF MAE 6.00/5.31 →
  앙상블(B=30) 평균 5.84/5.23. A3에서 점추정을 앙상블 평균으로 바꾸는 것을 검토한다.

### 채택
현행(평균 라벨 + 정규 CI) 유지. 경고문·서술문만 실측 편향 기준으로 수정.

  평균, 클럽 강도 대리변수)·팀 평균 대비 본인 능력·팀 강도 리그 내 순위·선발 비율·시즌 내 소속팀
  수·2시즌 전 출전시간과 2년 추세·리그 one-hot 5개. FBref `pt_*_Team_Success`(팀 승점·득실)는
  2024·2025 반입분에 없어 쓸 수 없었다 — 그래서 팀 강도는 데이터 안에서 직접 만들었다.
- `build/exp/a3a4_tune.py`: (A4) 51 vs 64 피처를 잔존·회귀 각각 GroupKFold 5겹 비교 →

  seed 7)에서 현행과 선택을 다시 평가**해 그것으로 채택 여부를 정했다.
- 채택 설정은 `build/hparams.json`, `07_train_models.py`·`03_predict.py`가 읽는다.
