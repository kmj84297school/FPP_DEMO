# FPP 활동 보고서 — 축구 선수의 2~3년 후를 예측하는 웹 서비스 만들기

**만든 사람** 고명준 (세마고 2학년) · **기간** 1학년 프로토타입 → 2학년 재구축 (~2026년 9월)
**결과물** GitHub Pages로 공개된 웹 서비스 (`docs/` 폴더가 그대로 사이트) · 저장소 `kmj84297school/FPP_DEMO`

> 이 보고서는 전문 지식이 없어도 읽을 수 있게 썼습니다. 어려운 용어는 그때그때 괄호로 풀어 씁니다.
> 수치는 전부 실제로 측정한 값이며, 측정하지 않은 것은 "측정하지 않았다"고 적었습니다.

---

## 1. 한 문단 요약

축구 선수의 **지금 실력**을 공개 데이터로 점수화하고, **2~3년 뒤에 어떻게 될지**를 예측하는 웹 서비스를 만들었습니다.
2018~2025년 유럽 5대 리그 선수 기록 약 2만 건을 모아, "이런 스탯을 가진 선수는 2~3년 뒤 실제로 어떻게 됐는가"를
컴퓨터가 학습하게 했습니다. 지금은 **1,692명을 검색**할 수 있고 그중 **1,455명에게 미래 예측**을 제공합니다.
가장 신경 쓴 것은 성능이 아니라 **정직함**입니다. 예측이 얼마나 틀리는지, 어디부터는 못 믿는지를 화면에 같이 띄웁니다.

---

## 2. 왜 시작했나 — 1학년 버전의 벽

1학년 때 만든 첫 버전은 "사용자가 선수 이름을 넣으면 그때 사이트에서 기록을 긁어와(크롤링) 점수를 계산"하는 방식이었습니다.
여기서 네 가지 벽에 부딪혔습니다.

| 문제 | 내용 |
|---|---|
| 차단 | 데이터를 가져오던 사이트가 자동 접속을 막음 |
| 속도 | 한 명 조회에 수십 초 |
| 배포 불가 | 서버에 올리면 곧바로 차단당해 남에게 보여줄 수 없음 |
| **학습 불가** | 데이터를 그때그때 가져오니 **쌓인 데이터가 없어 머신러닝 자체가 불가능** |

게다가 점수 계산식의 가중치를 제가 임의로 정했기 때문에 "이 점수가 맞다"고 말할 근거가 없었습니다.
그래서 2학년에는 **구조를 완전히 갈아엎기로** 했습니다.

---

## 3. 무엇을 바꿨나 — 구조 전환

```
[1학년]  조회할 때마다 실시간 크롤링  →  내가 정한 규칙으로 점수  →  리포트
[2학년]  데이터를 미리 다 모아둠      →  실제 결과로 학습한 모델  →  웹은 결과만 읽어서 보여줌
```

이렇게 바꾸니 크롤링이 0회가 되어 **즉시 응답**하고, 서버 없이 **정적 웹사이트로 배포**할 수 있고,
무엇보다 **진짜 머신러닝 학습**이 가능해졌습니다.

## 4. 어떻게 만들었나 — 다섯 단계

**① 데이터 모으기.** 공개 아카이브(worldfootballR, 원출처 FBref)에서 2018~2023 시즌을 받고,
2023-24·2024-25 시즌은 형식이 다른 파일을 따로 변환해 붙였습니다. 최종 **19,789행 × 169열**(2018~2025).

**② 현재 능력 점수 만들기.** 선수의 스탯을 *같은 시즌·같은 포지션 선수들 사이의 순위*로 바꿔 100점 만점 점수를 만듭니다.
포지션만으로 재면 공격형 풀백 같은 선수가 손해를 보므로, **포지션 렌즈 + 플레이스타일 렌즈** 두 가지로 재서 평균을 냅니다.
(예: 트렌트 알렉산더-아널드는 포지션 렌즈 49.5점이지만 스타일 렌즈로는 69.1점)

**③ "정답" 정하기.** 2018~2022 시즌 선수마다 **2~3년 뒤 실제 능력 점수**를 정답으로 붙였습니다.
빅5 리그에서 사라진 선수는 점수를 매길 수 없으므로 **"남아 있을 확률"을 따로 예측하는 모델**로 분리했습니다.

**④ 학습·검증.** XGBoost라는 모델을 씁니다. 검증할 때는 **같은 선수가 문제지와 시험지에 동시에 들어가지 않도록**
선수 단위로 나눠서(GroupKFold) 측정했습니다. 나이대에 따라 성장기(23세 이하)와 성숙기(24~38세) 모델을 따로 만들었습니다.

**⑤ 웹으로 만들기.** 계산은 전부 미리 끝내 JSON 파일로 저장하고, 웹은 그것만 읽습니다.
검색·필터·선수 상세·두 선수 비교 페이지가 있고, 휴대폰에서도 잘 보이게 만들었습니다.

## 5. 성능 — 실제로 측정한 값

전부 **GroupKFold 5겹**(선수 단위로 5번 나눠 검증)으로 측정했습니다.

| 항목 | 성장기 모델 (23세 이하) | 성숙기 모델 (24~38세) |
|---|---|---|
| 빅5 잔존 예측 정확도 (AUC) | 0.745 | 0.759 |
| 미래 능력 평균 오차 (MAE) | 5.79점 | 5.18점 |
| 설명력 (R²) | 0.346 | 0.521 |
| 80% 구간이 실제로 맞은 비율 | 81.1% | 82.9% |
| 학습에 쓴 선수-시즌 수 | 2,268건 (정답 있는 것 1,637건) | 5,214건 (2,800건) |

읽는 법:
- **MAE 5.79** = 2~3년 뒤 능력을 맞힐 때 평균 5.79점(100점 만점 기준) 틀린다는 뜻.
- **80% 구간 81.1%** = "80% 확률로 이 범위"라고 말한 구간에 실제 결과가 81.1% 들어왔다는 뜻. 약속과 실제가 맞습니다.
- 재미있는 발견: **베테랑 예측이 유망주 예측보다 정확합니다.** 이미 자리 잡은 선수의 하락 곡선이,
  아직 증명되지 않은 유망주의 "터질지 말지"보다 예측하기 쉽기 때문입니다.

## 6. 실패하고 고친 것들 (이 프로젝트의 핵심)

성능 자랑보다 이 목록이 더 중요합니다. 전부 기록으로 남겼습니다.

**① 신뢰구간 1차 실패 → 원인 규명 → 해결**
"80% 확률로 이 범위"라고 말했는데 실제로는 **29.3%**만 맞았습니다. 모델 자체의 흔들림만 계산하고
데이터에 원래 있는 오차를 빼먹은 게 원인이었습니다. 두 가지를 합쳐 다시 계산하니 **약속대로 82%**가 됐습니다.

**② "왜 최고 선수가 하락 예측인가" → 근본 원인 발견 → 해결**
현재 88점인 선수의 2~3년 후 예측이 73점으로 나왔습니다. 조사해 보니 **학습 데이터의 정답 중 85점 이상이 0명**이라,
모델이 구조적으로 74점 위를 예측할 수 없던 것이었습니다. 그래서 "몇 점이 될까"가 아니라
**"몇 점 오르내릴까(변화량)"를 학습**하도록 바꿨더니 같은 선수가 82점으로 나왔고, 정확도도 함께 좋아졌습니다.

**③ 시도했지만 지표가 나빠져서 버린 것 (3건)**
- 포지션을 7개 역할(센터백·풀백·수비형MF…)로 쪼개 채점 → 오차가 5.79→7.10으로 **악화**해서 폐기. 역할은 화면 표시용으로만 남김.
- 정답을 "두 시즌 평균" 대신 "최댓값"으로 → 악화.
- 구간을 다른 방식(분위수 회귀)으로 계산 → 약속한 80%가 실제 69%밖에 안 돼서 폐기.

**④ 데이터 오류 2건 직접 발견·수정**
- 한 구단(울버햄프턴) 폴더가 중복이라 그 팀 선수 10명의 기록이 **2배로 합산**되고 있었음.
- 동명이인 6쌍(예: 다닐루 22세/32세)이 **한 사람으로 합쳐져** 있었음. → 이름+생년으로 구분하도록 수정.

**⑤ 이름 표현도 고쳤습니다**
처음엔 예측값을 "잠재력 상한"이라고 불렀는데, 모델이 예측하는 건 커리어 전성기가 아니라 **정확히 2~3년 후**라서
화면 문구를 전부 기간 명시로 바꿨습니다. *측정한 것보다 큰 주장을 하는 이름은 그 자체로 결함*이라고 판단했습니다.

## 7. 지금 웹에서 할 수 있는 것

- **검색·필터**: 리그·포지션·세부 역할·나이대·플레이스타일·예측 대상 여부로 좁히기. 필터 상태가 주소(URL)에 저장돼 그대로 공유 가능.
- **세 가지 정렬**: 현재능력순 / 2~3년 후 상한순 / **상승 여력순**(숨은 유망주 찾기).
- **선수 카드**: 위쪽 두 숫자가 `현재`와 `2~3년 후 상한`. 게임 카드처럼 보이지만 숫자의 뜻은 정확히 표기합니다.
- **선수 상세**: 능력 그룹 레이더, 강점·약점, 플레이스타일 판별 근거, 예측 구간, **실제 결과가 있는 과거 유사 선수 10명**,
  경기 기록 기반 정성 시그널(경고·파울·출전 점유율·기복).
- **왜 이 예측인가 (SHAP)**: 어떤 항목이 예측을 얼마나 올리고 내렸는지 선수마다 표시. 예측을 "블랙박스"로 두지 않기 위한 장치.
- **두 선수 비교**: 레이더를 겹쳐 보고 항목별 차이를 표로.

디자인은 축구 게임(EA FC)·스카우팅 사이트들을 참고해 다크 테마 + **별과 궤도** 로고로 통일했고,
"현재 → 2~3년 후"를 한 궤도 위의 두 점으로 그리는 표현을 프로젝트 상징으로 삼았습니다.

## 8. 지금의 한계 (숨기지 않고 기록)

- **유망주 예측의 설명력은 0.35**입니다. 즉 2~3년 뒤 변화의 65%는 아직 설명하지 못합니다. 그래서 구간을 넓게 보여줍니다.
- **아주 잘하는 선수(상위 1%, 19명)** 는 비슷한 학습 사례가 적어 "모델 검증 범위 밖"이라고 경고를 띄웁니다.
- **정답의 순환성**: 능력 점수로 능력 점수를 예측하는 구조라, 시장가치 같은 **외부 지표로 검증**해야 완성됩니다.
  (검증 스크립트와 선수 ID 연결표는 이미 준비해 뒀고, 데이터만 확보하면 바로 돌아갑니다.)
- 2023-24·2024-25 시즌 신규 선수 일부는 고유 ID를 확보하지 못해 과거 이력과 연결되지 않습니다(사진도 없음).
- **골키퍼 전용 모델은 미착수**입니다. 필드플레이어와 평가 축이 완전히 달라 별도 설계가 필요합니다.
- **라이선스**: 교육·연구 목적은 문제없지만 **상업적 사용은 불가**합니다(데이터 출처 정책).

### 부록 — 용어 한 줄 설명

- **MAE(평균절대오차)**: 예측이 평균 몇 점 틀리는지.
- **R²(설명력)**: 1에 가까울수록 잘 설명. 0.35면 변화의 35%를 설명한다는 뜻.
- **AUC**: 분류 정확도 지표. 0.5는 찍기, 1.0은 완벽. 0.75면 꽤 쓸 만한 수준.
- **GroupKFold**: 같은 선수가 학습·검증에 동시에 들어가지 않도록 나누는 검증법. 안 그러면 성적이 부풀려짐.
- **SHAP**: 이 예측에서 각 항목이 얼마나 기여했는지 계산하는 방법.
- **신뢰구간**: "이 범위 안에 있을 것"이라고 제시하는 범위. 넓을수록 불확실하다는 뜻.
